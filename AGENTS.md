# AGENTS.md

## Project Language

All project-facing content must be written in English. This includes source strings, documentation, comments, commit messages, issue/PR text, and repository metadata.

## Git Workflow

Always create a local git commit after making project changes. Do not push commits unless the user explicitly asks for a push.

## Context Check

If work is already in progress and the user suddenly sends a task that is completely unrelated to this project, ask whether they meant to send it in this chat. If they confirm, proceed.
